# AML Desk

Aplikace AML Desk pro macOS (Intel i Apple Silicon).

## Stažení

**[Stáhnout nejnovější verzi (AML-Desk.dmg)](https://github.com/fixiee/aml-desk-releases/releases/latest/download/AML-Desk.dmg)**

Seznam změn je na [stránce posledního vydání](https://github.com/fixiee/aml-desk-releases/releases/latest). Ostatní soubory u vydání (`.tar.gz`, `.sig`, `latest.json`) slouží automatickým aktualizacím, nestahujte je.

## Instalace

1. Otevřete stažený soubor `AML-Desk.dmg` a přetáhněte aplikaci AML Desk do složky Aplikace.
2. Při prvním spuštění macOS aplikaci zablokuje, protože není podepsaná u Applu. Klikněte na ni pravým tlačítkem, zvolte Otevřít a potvrďte Otevřít. Případně Nastavení systému → Soukromí a zabezpečení → Přesto otevřít.
3. Další verze nabídne aplikace sama, najdete je také v Nastavení → Aktualizace.
